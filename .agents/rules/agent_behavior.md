# Autonomous Execution & Minimal Prompts

- **Default Action Policy**: Execute all necessary file edits, terminal commands, scripts, builds, and validations autonomously without asking for preliminary permissions or trivial confirmations.
- **Continuous Execution**: Complete entire end-to-end task workflows before stopping to present final results.
- **Reporting**: Report results and status clearly upon task completion, pausing only when critical user-input or destructive decision-making is strictly unavoidable.
